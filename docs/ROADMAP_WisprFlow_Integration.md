# نقشه راه (Roadmap) توسعه OmniType-FreePTT
**معماری محلی و آفلاین (Local-First)**

این سند مسیر اجرایی برای ارتقای `OmniType-FreePTT.py` به یک نرم‌افزار حرفه‌ای، با تاخیر صفر و کاملاً آفلاین را مشخص می‌کند. هدف این معماری حذف کامل هزینه‌های کلاد، حفظ حریم خصوصی ۱۰۰ درصدی و استفاده بهینه از سخت‌افزار (مانند RTX 4050) است.

---

## 🏗️ معماری نهایی (سه پروفایل کاربری)

نرم‌افزار از سه حالت (Profile) پشتیبانی خواهد کرد که کاربر می‌تواند بین آن‌ها جابجا شود:

1. **Fast & Private (پیش‌فرض):** 
   `PTT → Faster‑Whisper (Turbo) محلی → اصلاحات قطعی (Normalizer) → Paste`
   *(کمترین تاخیر، بدون احتمال توهم، کاملاً آفلاین)*
2. **Smart Offline:**
   `PTT → Faster‑Whisper محلی → Qwen3 (1.7B/4B) محلی → Paste`
   *(اصلاحات معنایی پیشرفته، نیازمند VRAM بیشتر، کاملاً آفلاین)*
3. **Free Cloud:**
   `PTT → Cloudflare Workers AI (یا Groq Free) → Paste`
   *(برای سیستم‌های ضعیف‌تر یا ذخیره باتری لپ‌تاپ، نیازمند اینترنت)*

---

## 🛠️ مراحل اجرایی (Execution Order)

### فاز ۱: زیرساخت ASR محلی و Benchmark
- [ ] افزودن کلاس `FasterWhisperProvider` بدون حذف کدهای Google (پیاده‌سازی پشت Feature Flag).
- [ ] دانلود و اجرای مدل `large-v3-turbo` با تنظیمات `int8_float16` روی CUDA.
- [ ] تست و Benchmark مدل روی سخت‌افزار فعلی (اندازه‌گیری دقیق p50 و p95 از لحظه رها کردن کلید تا تولید متن).
- [ ] اندازه‌گیری میزان مصرف دقیق VRAM در زمان اجرا.

### فاز ۲: ساخت Normalizer قطعی (لایه ویرایشگر سریع)
- [ ] پیاده‌سازی سیستم اصلاحات قطعی (Regex-based) برای زبان فارسی:
  - اصلاح حروف عربی به فارسی (ي → ی، ك → ک).
  - حذف فاصله‌های تکراری و اصلاح فاصله‌گذاری علائم نگارشی.
  - اعمال نیم‌فاصله‌های ایمن و تبدیل اختیاری اعداد به فارسی.
  - حذف کلمات پرکننده (Filler) فقط از یک لیست بسیار محدود و با احتیاط.

### فاز ۳: مدیریت چرخه حیات مدل و سخت‌افزار (Optimization)
- [ ] **مدیریت Cold Start:** لود کردن مدل در VRAM به صورت پس‌زمینه در زمان اجرای اولیه برنامه، تا اولین درخواست کاربر با تاخیر مواجه نشود (Warm-up).
- [ ] **مدیریت VRAM:** ایجاد مکانیزم آزادسازی VRAM در صورت عدم استفاده طولانی‌مدت (Idle Timeout) تا در صورت اجرای بازی یا نرم‌افزارهای سنگین، گرافیک درگیر نماند.

### فاز ۴: پایداری و تایپ ایمن (Robustness)
- [ ] ذخیره Focus پنجره در زمان فشردن PTT و بررسی مجدد آن قبل از Paste کردن.
- [ ] حفظ و بازیابی محتوای قبلی Clipboard کاربر.
- [ ] تست سیستم تایپ در برنامه‌های Elevated (Run as Admin) و فیلدهای حساس.

### فاز ۵: افزودن لایه LLM محلی (اختیاری)
- [ ] اتصال به `Ollama` یا پیاده‌سازی مستقیم `llama.cpp` برای اجرای `Qwen3 1.7b` یا `4b`.
- [ ] مهندسی پرامپت (Temperature=0, خروجی کوتاه، عدم تغییر لحن).
- [ ] تست روی ۵۰ جمله واقعی فارسی.
- [ ] پیاده‌سازی Fallback: اگر LLM خطا داد، طولانی شد یا خروجی نامعتبر داشت، مستقیماً خروجی خام ASR تایپ شود.

### فاز ۶: افزودن Cloud به عنوان گزینه جایگزین
- [ ] پیاده‌سازی `CloudflareProvider` به عنوان پروفایل سوم با استفاده از مدل `whisper-large-v3-turbo` روی Cloudflare Workers AI.

### فاز ۷: صیقل‌کاری نهایی و انتشار
- [ ] به‌روزرسانی UI برای نمایش وضعیت پروفایل‌ها و لود شدن مدل‌ها.
- [ ] حذف کامل نیاز به API Key در حالت پیش‌فرض برنامه.
- [ ] به‌روزرسانی فایل `README.md` با تمرکز بر ویژگی‌های آفلاین بودن و حفظ حریم خصوصی.
